# AI2Zed Quote Form

A simple quote request form built with Next.js and Tailwind CSS for a renovation business.

## Live Demo
[View Live Site](https://ai2zed-quote-form.vercel.app/quote)

## Features
- Quote request form
- Dark and light mode
- Success message after submit
- Console logging for testing
- Mobile tested
- Deployed on Vercel

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Vercel

## Purpose
This project was built for a real renovation business to collect quote requests from potential clients.
